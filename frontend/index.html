Hệ thống hoạt động thế nào

Trang web này chỉ là giao diện. Phần xử lý nằm hoàn toàn trên các dịch vụ AWS.

Luồng dữ liệu

  1. Trang web (lưu trên S3) gửi tin nhắn tới API Gateway.
  2. API Gateway kích hoạt hàm Lambda.
  3. Lambda nạp mô hình từ S3 và dự đoán spam hoặc không.
  4. Lambda ghi lần dự đoán vào DynamoDB.
  5. Kết quả trả về trang web.
  6. CloudWatch ghi số request, độ trễ, lỗi và gửi cảnh báo.

Dịch vụ sử dụng

S3Chứa trang web và file mô hình
API GatewayNhận yêu cầu, bật CORS, giới hạn lưu lượng
LambdaChạy suy luận, tự co giãn khi nhiều người dùng
DynamoDBLưu lịch sử mỗi lần dự đoán
CloudWatchDashboard và cảnh báo
